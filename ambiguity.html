Ambiguity

A grammar is ambiguous when one string has more than one parse tree. Both trees below derive the same string from the same grammar.

GrammarE → E + E | E * E | id
Stringid + id * id
1+ at the rootid + (id * id)

The root uses E → E + E. The * is grouped first, lower in the tree, so with numbers 2 + 3 * 4 this tree means 2 + 12.

2* at the root(id + id) * id

The root uses E → E * E. Now + is grouped first, so the same 2 + 3 * 4 would mean 5 * 4.

THE FIX

One nonterminal per operator

T handles *, and T only appears below E. So * always ends up deeper than +, and id + id * id has exactly one tree. The language stays the same.

E → E + T | TT → T * F | FF → id

Unambiguous. The builder replays this one on a loop.
