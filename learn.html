1. What is a context-free grammar?

A context-free grammar (CFG) is a small set of rewriting rules. It has four parts:

  • Nonterminals (variables), written in UPPERCASE, such as S. They still need to be rewritten.
  • Terminals, the actual characters of the language, such as a and b.
  • Productions such as S → aSb: “an S may be replaced by aSb”. The bar | lists alternatives, and ε is the empty string.
  • A start symbol, where every derivation begins.

“Context-free” means a rule can rewrite a nonterminal no matter what surrounds it. The grammar S → aSb | ε generates exactly the strings aⁿbⁿ.

2. Derivations

A derivation starts from the start symbol and applies one production at a time. Each intermediate string is a sentential form, and we join them with ⇒:

S ⇒ aSb ⇒ aaSbb ⇒ aabb

In each step one nonterminal (underlined in the animation) is replaced by the right-hand side of one of its rules. When no nonterminals are left, the derivation has produced a string of the language.

3. Leftmost and rightmost derivations

When a sentential form contains several nonterminals, we must choose which one to rewrite.

  • A leftmost derivation always rewrites the leftmost nonterminal.
  • A rightmost derivation always rewrites the rightmost one.

With S → AB, A → aA | a, B → bB | b and the string aabb, both orders use the same productions and end in the same tree. Only the order of growth differs.

4. Derivation (parse) trees

A derivation tree records which production was used where, without recording the order.

  • The root is the start symbol.
  • Each nonterminal node has the symbols of its production as children, left to right.
  • Leaves are terminals or ε.

5. Yield of a tree

The yield of a derivation tree is the string you get by reading its leaves from left to right, skipping ε.

Every derivation tree whose root is the start symbol and whose leaves are all terminals yields a string of the language, and every string of the language is the yield of at least one such tree.

The yield of this tree is aabb: the ε leaf contributes nothing.

6. Ambiguity

A grammar is ambiguous if some string has two different derivation trees (equivalently, two different leftmost derivations).

Under E → E + E | E * E | id, the string id + id * id can be grouped as id + (id * id) or as (id + id) * id. The highlighted nodes are where the trees differ.

Ambiguity can hide in small places. Under S → (S) | SS | ε, even () has two trees: S ⇒ (S) ⇒ (), and S ⇒ SS ⇒ S ⇒ (S) ⇒ (), where the first S becomes ε. Since S can derive itself, there are infinitely many trees.

There is no general algorithm that decides whether a CFG is ambiguous. A search can find two trees for a particular string, but not finding them does not prove the grammar is unambiguous.
